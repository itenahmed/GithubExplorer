# GitHub Profile Explorer

This project lets you search for any GitHub user and view their profile details, repositories, and some basic stats.  
You can also write personal notes for each user or repository (saved locally on your device).

## Features

- Search GitHub users and see their public repos
- Add notes for users and repositories
- Compare two GitHub users
- Generate a short AI summary for any user (optional)

## How to run

1. Install dependencies  
   `npm install`

2. Start the project  
   `npm run dev`

3. Open it in your browser  
   `http://localhost:3000`
